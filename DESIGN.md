# Редизайн «Восточная рукопись» — Design System

Новая визуальная система вместо прежней «Apple / Notion»-минималистской.

## Концепция

Тёплая «бумага» цвета слоновой кости вместо холодного серого, глубокий
изумруд в паре с благородным золотом, арабский геометрический орнамент
«гирих» (восьмиконечная звезда) в hero-блоках и футере, тёплая бронзовая
ночная тема. Шрифт Unbounded — только для фирменных заголовков (`.font-brand`).

## Что изменилось

| Файл | Изменение |
| --- | --- |
| `tailwind.config.js` | Шкала `slate` заменена на тёплую песочно-графитовую; `amber` алиасится на золото (`gold`); тени потеплели; добавлены `emerald-750/850`, `glow-gold` |
| `src/index.css` | Токены поверхностей (ivory `#F6F3EA` / бронзовая ночь `#100F0A`), новый `.hero-mesh-gradient` (изумруд+золото), орнаменты `.hero-arabesque` / `.pattern-girih`, золотые `.ornament-line` / `.diamond` / `.text-gold-grad`, тёплые стёкла, тёмно-изумрудный `.glass-dock` для мобильного дока |
| `src/components/Navbar.jsx` | Логотип с золотым кольцом, тёплая шапка с золотой кромкой (`glass-header::after`), изумрудная активная секция, тёмный изумрудный мобильный док |
| `src/components/LessonsView.jsx` | Hero с орнаментом гирих и золотым прогресс-баром, золотая шапка шпаргалки, изумрудные пилюли глав, тёплые карточки уроков с золотыми линиями |
| `src/App.jsx` | Фон-канва на `body`, тёплые ambient-пятна, тёмный изумрудный футер с орнаментом и золотой статистикой |
| `index.html` | `theme-color` под новую канву, тёплый `dark:bg`, изумрудная селекция |
| Остальные views | Hero-блоки автоматически получили новый градиент; все карточки массово переведены `bg-white → bg-[#FFFDF8]`, тёмные границы `white/5 → gold-200/15` |

## Как откатить
